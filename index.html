¿Qué es el desarrollo web?

El desarrollo web es el proceso de crear y mantener sitios y aplicaciones que funcionan mediante navegadores. Combina diferentes tecnologías para presentar información y permitir que los usuarios interactúen con ella.

Entre las tecnologías fundamentales encontramos HTML, que organiza el contenido; CSS, que define su apariencia; y JavaScript, que permite agregar interactividad.

Las tres tecnologías principales

HTML

HTML

Define la estructura y el significado del contenido de una página web.

CSS

CSS

Controla los colores, las fuentes, los espacios y la distribución visual del sitio.

JS

JavaScript

Añade funciones interactivas, como validar formularios y responder a las acciones del usuario.

Un poco más sobre la web

La web permite consultar y compartir información a través de documentos y recursos enlazados. Aunque muchas veces se confunde con Internet, no son exactamente lo mismo: Internet es la infraestructura de redes y la web es uno de los servicios que funciona sobre ella.
