La historia de la web

La World Wide Web transformó la forma de consultar, compartir y publicar información. Conoce algunos de los acontecimientos que marcaron su evolución.

¿Cómo surgió la World Wide Web?

La World Wide Web fue propuesta en 1989 por Tim Berners-Lee mientras trabajaba en el CERN. Su idea consistía en conectar documentos mediante enlaces para facilitar el acceso a la información.

La web comenzó a utilizarse fuera del CERN en 1991. Desde entonces, ha evolucionado desde páginas sencillas de texto hasta plataformas interactivas, servicios móviles y aplicaciones que utilizamos todos los días.

Línea del tiempo de la evolución de la web

Estos son algunos momentos importantes de la historia de las redes y tecnologías que hicieron posible la web actual.

1969 — ARPANET

ARPANET establece una de las primeras redes de computadoras que contribuyeron al desarrollo de Internet.

1983 — TCP/IP

ARPANET adopta TCP/IP, un paso fundamental para la comunicación entre redes.

1989 — Propuesta de la web

Tim Berners-Lee presenta una propuesta para organizar y compartir información mediante documentos relacionados entre sí.

1990 — Primer servidor y navegador

Se desarrollan las primeras herramientas de la World Wide Web, incluido un navegador y un servidor web.

1991 — La web se comparte

El sistema comienza a estar disponible para personas ajenas al CERN.

1993 — Navegador Mosaic

Mosaic ayuda a popularizar la navegación web gracias a su interfaz gráfica.

1994 — Fundación del W3C

Se crea el World Wide Web Consortium para promover estándares abiertos para la web.

1995 — JavaScript

JavaScript introduce nuevas posibilidades de interacción en las páginas web.

2004 — Web 2.0

Se populariza el término Web 2.0, asociado con servicios participativos y contenido generado por los usuarios.

2007 — Expansión de la web móvil

El lanzamiento del iPhone impulsa una nueva etapa en el uso de navegadores y servicios web desde dispositivos móviles.

2014 — HTML5

HTML5 se convierte en una recomendación del W3C, incorporando capacidades útiles para el contenido multimedia y las aplicaciones web.

2020 en adelante — Web moderna

Se extiende el uso de aplicaciones web avanzadas, servicios en la nube, diseños adaptables y nuevas funciones basadas en inteligencia artificial.

¿Por qué es importante conocer esta historia?

Conocer la evolución de la web ayuda a comprender por qué existen los estándares actuales y cómo las tecnologías continúan cambiando para ofrecer mejores experiencias.
