Aprende HTML

Elementos que forman una página web

HTML cuenta con etiquetas que permiten organizar el contenido y darle significado. Conocerlas es uno de los primeros pasos para desarrollar sitios web.

Encabezados y párrafos

Los encabezados permiten dividir el contenido en secciones. HTML ofrece seis niveles, desde h1 hasta h6. Se recomienda mantener un orden lógico para que la información sea fácil de entender.

Ejemplo de un encabezado de tercer nivel

Los párrafos se escriben con la etiqueta p. Para resaltar una palabra podemos usar negritas, mientras que la etiqueta em permite dar énfasis al texto, normalmente mostrándolo en cursiva.

Un encabezado de cuarto nivel

También podemos agregar enlaces, imágenes, listas, tablas y formularios para presentar información de distintas maneras.

Listas en HTML

Lista desordenada

Una lista desordenada se utiliza cuando el orden de los elementos no es importante.

  • Diseño de interfaces.
  • Organización del contenido.
  • Programación de funciones.
  • Pruebas y mantenimiento.

Lista ordenada

Una lista ordenada sirve para mostrar pasos que siguen una secuencia.

  1. Crear el archivo HTML.
  2. Vincular la hoja de estilos CSS.
  3. Agregar interactividad con JavaScript.
  4. Probar el sitio en un navegador.

Tabla de tecnologías web

La siguiente tabla resume la función de algunas tecnologías utilizadas durante la creación de un sitio web.

Tecnología Función principal Ejemplo de uso
HTML Organizar el contenido Títulos y párrafos
CSS Definir la apariencia Colores y distribución
JavaScript Agregar interactividad Validar un formulario
SQL Consultar información Buscar registros
Resumen: cada tecnología cumple una función diferente y puede trabajar junto con las demás.

Buenas prácticas

Recomendaciones al escribir HTML

  • Utilizar etiquetas de acuerdo con su propósito.
  • Escribir el código con una indentación ordenada.
  • Agregar textos alternativos a las imágenes.
  • Comprobar que los enlaces funcionen correctamente.
  • Separar el contenido HTML del diseño CSS.
